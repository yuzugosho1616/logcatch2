# LogCatch

巨大な `.log` ファイルから指定ワードを含む行を抽出する、Windows向けPythonアプリです。ファイル全体をメモリへ読み込まず、1MBずつストリーミング処理します。

## 起動

```powershell
python logcatch.py
```

依存パッケージがない環境では、先に次を実行します。

```powershell
pip install -r requirements.txt
```

## 主な機能

- 複数の `.log` ファイルをドラッグ＆ドロップ
- ファイルの絶対パスを一覧と抽出結果に表示
- 入力欄を追加できる、文字数・語数制限のない検索条件
- 条件グループによるAND／ORの組み合わせ検索
- UTF-8／Shift_JIS（CP932）の自動判定と手動指定
- バックグラウンド抽出、進捗表示、中止
- 処理中の経過時間と完了後の所要時間を表示
- 結果をUTF-8のログファイルへ逐次保存
- 全結果のクリップボードコピー、名前を付けて保存、結果ファイルを開く
- 読み込めないファイルを結果内に記録し、残りのファイルを継続処理

抽出結果は開始時に自動で `results/logcatch_YYYYMMDDHHMMSS.log` へ保存されます。正常完了だけでなく、中止・入力ファイルのエラー・アプリ終了でも削除されません。同じ秒に開始した同名ファイルがある場合は `_2`、`_3` のような連番が付きます。

一部の入力ファイルを開けない、または読み込めない場合、そのファイルには `[===Error File :...==]` が記録されます。抽出処理は停止せず、次のファイルへ進みます。保存先そのものへ書き込めない場合など、処理を継続できないエラーだけが全体エラーになります。

検索語は1つの入力欄に1つずつ指定します。カンマは区切り記号ではないため、`DD,E,FF`もその文字列のまま検索できます。各条件グループ内と複数グループ間で、それぞれ「すべて含む（AND）」または「いずれかを含む（OR）」を選択できます。

画面のプレビューは動作を軽くするため最新5,000行ですが、「全結果をコピー」と保存は自動保存されたログ内の全抽出結果を対象にします。100MBを超える結果をコピーする場合は確認が表示されます。

## テスト

```powershell
python -m unittest -v
```

## EXEの作成

ビルド用依存パッケージをインストールし、スクリプトを実行します。

```powershell
pip install -r requirements-build.txt
.\build_exe.ps1
```

単一ファイルのWindows GUIアプリとして `dist\LogCatch.exe` が生成されます。抽出結果の `results` フォルダーは、実行したEXEと同じフォルダーに作られます。

従来のブラウザ版は `logcatch.html` として残しています。
